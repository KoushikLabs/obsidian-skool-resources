# InfluenceMap

**Type:** Organization overview  
**Raw file:** [[raw/InfluenceMap Overview]]  
**URL:** https://influencemap.org

## Summary

InfluenceMap is the leading real-time tracker of corporate climate policy lobbying — the direct analogue for what a context monitoring system for animal welfare would look like. Running since 2015, weekly updates, 1,000 companies tracked, fully philanthropy-funded and independent. Demonstrates that this model works and is sustainable.

## Key Points

- **Weekly update cadence** — demonstrates near-real-time monitoring is operationally feasible
- **Public-data-only methodology** — reproducible, legally sound, credible
- **Independence is the product** — philanthropic funding preserves credibility; this is non-negotiable
- **Regional platforms** (Brazil, India) — shows country-specific adaptation is possible and necessary
- **Investor integration** — 32+ investors use LobbyMap data; creates sustainability beyond advocacy
- **Scoring framework** — 0-100 Paris alignment score makes complex data legible for non-experts

## Lessons for AW Context Monitoring

From [[wiki/opportunities/2026-04-17-realtime-context-monitoring|Context Monitoring opportunity]]:
1. Start with one domain (legislative tracking) not everything at once
2. Independence from any single advocacy org is essential for credibility
3. Country-specific adaptation requires significant investment — don't underestimate
4. Institutional investor integration (BBFAW already has this) creates a parallel funding pathway
5. The methodology documentation is public — directly transferable
