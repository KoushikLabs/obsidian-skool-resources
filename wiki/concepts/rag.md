## Notes

**Canonical definition (mine):** RAG = giving an LLM external data at query time so it can answer using that data instead of its pretraining alone.

**Tensions spotted across Nate's sources:**
- Chunk-based retrieval vs full-context retrieval — Nate argues chunking causes wrong answers on aggregation questions.
- Vector stores (Supabase) vs SQL for structured data — he prefers SQL when the question is quantitative.
